# 广告缓存与渠道初始化回归测试

在工程根目录运行：

```sh
node --test tests/*.test.cjs
```

默认使用 macOS DevEco Studio 自带的 TypeScript。其他环境可通过
`ADVANCE_TYPESCRIPT_PATH` 指定 TypeScript 包目录，无需新增工程依赖。

测试直接转译并执行核心库和六类广告的 `.ets` 源码，模拟系统时钟、窗口、网络和渠道初始化，
覆盖缓存过期、默认有效期、有效缓存不覆盖、按对象匹配删除、缓存命中元数据、
展示/渲染前删除、缓存回调重放及初始化超时。真机 UI 展示和渠道 SDK 行为仍需设备联调。

渠道初始化测试执行实际的 `AdvanceADNManager`，模拟渠道模块导入，覆盖配置类缺失时
所有并发请求返回相同错误、等待队列清空、失败后重试和 SDK 初始化错误透传。

渠道描述表测试校验内置描述与各模块 `Index.ets` 导出一致、自定义渠道全量替换与冲突处理、
各广告类型按需创建、不支持的类型跳过导入，以及按描述表收集版本号时不初始化渠道 SDK。

SDK 初始化使用 `AdvanceSDK.start()`，测试覆盖缓存优先、首次请求后完成 Promise、后台更新、
失败重试和缓存读写异常，并验证自定义渠道表在启动成功前同步完成。

渠道映射统一维护在 `AdvanceAdapterRepository.ets`。每条描述包含模块名、配置类名、
版本参数名和支持的广告类型映射；新增内置渠道只需在此添加一条描述。
自定义渠道由启动缓存及后台更新同步，媒体无需额外注册。

缓存删除规则：

- 开屏、插屏、激励视频：调用 `showAd()` 时，在有效性检查和渠道展示之前移除对应缓存。
- Banner、模板信息流、自渲染信息流：竞胜后立即开始渲染，在媒体加载回调和渠道渲染之前移除。
- 删除时匹配 key 与 Adapter 身份；曝光、失败或渲染回调不再重复操作缓存。
- 缓存命中只回放加载结果，保留源请求 ID、价格和原始有效期，不重新写入缓存。
- 渠道模型的 `cache_timeout` 默认为 1800 秒，接口缺失、返回 `null` 或为 0 时沿用默认值。
  缓存管理器直接使用模型传入的有效期，不重复设置默认值。
